# 无尽卷轴 · Infinite Scroll of Now

> 一个永远停留在"此刻"的无限滚动体验

## 理念

这不是一个普通的网页。

当你滚动时，你以为自己在时间中前进或后退。但实际上，你永远停留在**此刻**。

内容在流动，文字来来去去，但你——观察者——始终在同一个点上。

这是一个关于"当下"的禅意实验。

## 核心机制

1. **无限滚动的幻觉**
   - 你可以无限向左或向右滚动
   - 但你的位置会被悄悄地重置到中心
   - 你永远在"此刻"，只是内容在变化

2. **循环的智慧**
   - 内容会循环出现
   - 但每次角度略有不同
   - 就像生活：相似的经历，不同的感悟

3. **呼吸的空间**
   - 竖排中文，像古代卷轴
   - 充足的留白
   - 给思考留出空间

## 技术实现

- **纯原生技术**：HTML + CSS + Vanilla JavaScript
- **竖排布局**：`writing-mode: vertical-rl`
- **动态平衡**：滚动位置自动重置，创造无限的幻觉
- **微妙变化**：相同内容的不同呈现方式

## 使用方法

直接在浏览器中打开 `index.html`

然后：
- 滚动鼠标滚轮（或触摸滑动）
- 观察文字的流动
- 注意背景中的"此刻"
- 感受这个矛盾：你在移动，又没有移动
